# Minimum Experiment Result: USDJPY 4h MA Crossover

**Date:** 2026-04-23
**Status:** **FAIL → FX 撤退確定**

---

## 実験条件

| 項目 | 値 |
|---|---|
| Pair | USDJPY 単独 |
| Timeframe | 4時間足 |
| Strategy | MA Crossover（shortEma のみ最適化） |
| Param grid | shortEma ∈ [5, 10, 15, 20, 25]、longEma=50、atrPeriod=14 |
| Data | 過去23ヶ月（2024-05-22 〜 2026-04-22）、2870 4h bars |
| WF | IS 500 / OOS 250 / Step 125 / **17 windows** |
| 初期資金 | 1,000,000 JPY / 1% リスク |
| Target | **OOS Sharpe ≥ 0.5** |

## 結果

| KPI | 実測 | 目標 | 判定 |
|---|---:|---:|:---:|
| **OOS Avg Sharpe** | **0.118** | ≥ 0.5 | ❌ |
| OOS Avg MAR | 5.181 | ≥ 0.3 | ✅ |
| OOS Avg PF | 3.054 | ≥ 1.2 | ✅ |
| OOS Max DD | 4.91% | ≤ 15% | ✅ |
| **IS→OOS Sharpe Drop** | **69.35%** | ≤ 50% | ❌ |

## 窓ごとの shortEma 選択（過学習評価）

17窓の最適 shortEma: 5, 5, 5, 5, 10, 20, 15, 20, 15, 15, 15, 25, 10, 5, 25, 15, 15

**結論: 最適値がぶれている** — 全期間で安定して機能する値が存在しない。各窓のISノイズに最適化されているだけ。

OOS Sharpe 内訳も極端: -1.03, -0.96, -0.93, -0.89, -0.83, -0.75, -0.34, 0.05, 0.05, 0.51, 0.52, 0.69, 0.97, 1.07, 1.14, 1.24, 1.49 — **約半数が負、残り半数が正という完全なランダムウォーク**。

## 所見

### なぜ MAR/PF は良いのに Sharpe が悪いのか

- OOS Max DD 4.91%（目標 15% 余裕クリア）
- OOS PF 3.05（目標 1.2 の2倍超）
- OOS MAR 5.18（目標 0.3 の17倍）

でも OOS Sharpe は 0.118。これは:
- トレード数が窓あたり 2〜12 と少ない（年率換算で 10〜50 トレード）
- **正負両極端の結果が混在** → 平均 Sharpe がゼロ付近
- リスク調整後で見ると、**この戦略は「たまたま当たる」だけ**

### IS→OOS 低下率 69%

- IS期間のshortEma選択がOOSで反転（IS shortEma=5 → OOS shortEma=15 等）
- 「IS で良かった値」が OOS で機能しない典型パターン
- 緩和閾値（50%）にすら届かない

## 判定

### FX撤退を確定

このリポジトリの価値:
- **FXでは勝てない** を実証的に確認した記録
- 日足WF（12組合せ × 18窓）→ 4h最小実験（1組合せ × 17窓）すべて FAIL
- 今後FX関連の話題が来たときの**根拠ある回答材料**

### 次のアクション

1. **auto-stock-trader の運用・改善に集中**
2. このリポジトリは**削除せず保管**（将来の参照用、再開用）
3. FX再挑戦は**強いエビデンスがない限り行わない**
