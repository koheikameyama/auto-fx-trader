## 所見

### 1. 7KPI中6KPI合格 — 構造的には大幅改善

唯一未達の OOS Avg Sharpe を除き、ロバスト性・トレード分散・収益性の各KPIはすべて合格ラインを上回った。これは「ノイズに最適化しているだけ」の状態ではなく、戦略構造自体に**何らかの再現可能なエッジが存在する**ことを示唆する。

### 2. 4h MA Crossover実験との比較 — 全項目で改善

| 指標 | 4h MA Crossover | 1h ORB | 改善 |
|---|---:|---:|:---:|
| OOS Avg Sharpe | 0.118 | 0.217 | +84% |
| IS→OOS Sharpe Drop | 69.35% | 36.00% | 大幅改善 |
| OOS Sharpe Stdev | 約 0.9 | 0.429 | 約半減 |
| OOS Winning Windows | 約 50% | 62.5% | ランダム超え |
| OOS Max DD | 4.91% | 8.06% | 許容範囲内で悪化 |

特に**IS→OOS低下率の 69% → 36%** は決定的な改善であり、過学習が支配的だった4h実験とは異なる「IS→OOSで再現可能なシグナル」が一定程度存在することを意味する。Sharpe stdevが半減しているのも、ノイズではなく構造的なリターン分布が形成されている証拠。

### 3. rangeHours=2 がほぼ全窓で選択 — 構造的安定性

16窓中14窓で `rangeHours=2` が最適選択された（残りは Window 1, 2 が `rangeHours=3`、Window 15 のみ `rangeHours=4`）。これは「窓ごとに最適値がぶれる過学習」とは対照的なパターンで、**ロンドンオープンの最初の2時間という時間構造そのものが安定したエッジを持つ**可能性を示す。4h MA Crossover実験では shortEma の最適値が窓ごとに 5/10/15/20/25 の間でランダムに振れていたのと真逆。

### 4. レジーム変化の可能性

OOS Sharpeの時系列を見ると明確な分断がある:

- **2024-12 〜 2025-08（Window 0-8）**: 9窓中7窓がプラス、最大 1.20。平均 約 0.41 で目標 0.5 にほぼ届く水準
- **2025-09 〜 2026-04（Window 9-15）**: 7窓中3窓のみプラス、平均 約 0.00。Sharpe劣化が顕著

この分断が「市場レジーム変化（為替介入後の円市場の構造変化など）」によるものか、「エッジの自然減衰（戦略がアービトラージで消化された）」によるものかは現データだけでは判別できない。フォワードテストや他ペアでの検証が必要。

### 5. なぜ MAR/PF が高いのに Sharpe が 0.5 に届かないのか

- OOS Avg MAR **7.065**（目標 0.3 の23倍）
- OOS Avg PF **1.303**（目標 1.2 をクリア）
- でも OOS Avg Sharpe は **0.217**

これは「**1日1トレードの日中完結戦略 × 日次標準偏差ベースの Sharpe** という組合せの構造的な相性問題」と解釈できる:

- 各 OOS窓のトレード数 = 29〜42（≒ 約2ヶ月の取引日40日に対し 0.7〜1.0 トレード/日）
- 戦略が動かない日（ブレイクアウト不発）は日次リターン = 0
- **Sharpe 分母（日次リターンの標準偏差）にゼロ収益日が大量に混入** → 分母は安定するが分子（平均日次リターン）も希薄化される
- 一方 MAR/PF は「実際にトレードした結果」だけを見るため高くなる

つまり「**Sharpe は連続的にポジションを持つ戦略のための指標**であり、日中スパースな ORB のような戦略には Sortino比 や MAR比のほうが本質的に適切」という疑念が浮上する。これは設計時には想定していなかった構造的課題。

## 判定 と 次のアクション

### 判定: PARTIAL_SHARPE

設計の判定マトリクスに従えば、Sharpe < 0.5 かつ IS→OOS低下率 ≤ 50% の組合せは「部分合格」。設計上、**事前宣言した1回限りの追試**が許される。

ただし「7KPI中6KPI合格」という結果は単純なFAIL（撤退）でも単純なPASS（次フェーズ）でもなく、**戦略構造自体には再現可能性がある一方、絶対水準が実用ラインに届かない**という中間状態を示している。

### 追試候補（ユーザーが選択 — 1回限り）

事前宣言の上で、以下のうち**1つだけ**を追試できる。実行する場合はユーザーが明示的に承認すること。

#### Option A: NYセッション ORB（12:00-20:00 UTC）
- ロンドン時間とは流動性構造が異なる（米経済指標発表時間）
- 同じ戦略構造が別時間帯でも機能するかでロバスト性を二重化検証
- 仮説: NYでも同程度に機能 → 構造的エッジの確証 / 機能しない → ロンドン特化

#### Option B: ストップ幅拡大（slAtrMultiplier 1.5 → 2.5）
- 現状は ATR×1.5 で早すぎる損切りが発生している可能性
- ストップ拡大で「大きく勝ったトレードがさらに伸びる」効果を検証
- 仮説: PF/MAR がさらに上昇し、Sharpe も底上げされる

#### Option C: ロンドン + NY 両セッション併用
- 1日2トレードまで許可、トレード頻度を倍加
- Sharpe分母のゼロ収益日を減らし、構造的に Sharpe を底上げ
- 仮説: トレード密度向上 → Sharpe絶対値が 0.5 ラインに到達

#### Option D: 主KPIを Sortino比 / MAR比 に変更
- 所見5の通り、スパース戦略には Sharpe が本質的に不利
- 同データで Sortino を計算し直し、業界水準（Sortino ≥ 0.7）と照合
- 仮説: Sortino では合格水準に届く → KPI設計の見直しでPASS判定

### ユーザーが追試を選ばなかった場合

戦略は「**探索済み・未採用**」状態として記録に残す。撤退ではないが、現時点ではフォワード運用には進まない。次に1h ORB を再開する場合は、追試または新データソース（ティック・センチメント等）が前提となる。

### 重要な注意

- 追試は**事前宣言した1つだけ**。複数試行は p-hacking に該当するため設計上禁止。
- 追試で改善しても「初回 PARTIAL → 追試 PASS」は実用化判断ではなく**探索的所見**として扱う（フォワードテスト含む追加検証が必要）。
- 「もう少し試したい」という心理的バイアスで連鎖的にパラメータを変えないこと。
