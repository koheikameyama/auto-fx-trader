# Future Data Sources Roadmap

**作成日**: 2026-04-28
**位置づけ**: 1h ORB凍結最終確定後、FX再開の前提条件として「新データソース導入」が必要となった。本書は候補データソースを体系的に評価し、将来の選択肢を整理する。本書時点では**実装計画ではなく評価のみ**。

---

## 評価軸

各候補を以下の3軸で評価:

- **コスト**: 取得・保管・ライセンス費用、実装工数
- **期待効果**: 予想される Sharpe/Sortino 改善幅、エッジ源の質
- **実現可能性**: 個人開発レベルで取得・処理・実運用可能か

評価は ★1〜5（5が最良）。

---

## 候補1: ティックデータ (tick / level-1 quotes)

| 軸 | 評価 | 詳細 |
|---|:---:|---|
| コスト | ★★★ | 過去データは Dukascopy / TrueFX で無料、ストレージ約 50-100GB/2年/通貨ペア |
| 期待効果 | ★★★ | スプレッド変動・マイクロ構造を活用したスキャルピング系戦略が可能になる。ただしリテール執行のレイテンシで取れるエッジは限定的 |
| 実現可能性 | ★★ | バックテストは可能だが、ライブ実行には ECN ブローカー + 低レイテンシ環境（< 100ms）が必須 |
| **総合** | **★★** | バックテストでエッジ確認しても、リテール環境で再現できるかが大きな不確実性 |

### 想定される戦略
- スプレッド薄期の集中執行（流動性プールタイミング）
- セッション切替時（Asia→London）のオープニング・モメンタム
- 経済指標発表前後のマイクロ構造変化

### 注意点
- 1ティック = 1秒未満の更新が日常で、データ量は1h足の桁違い
- バックテストフレームワークの大規模改修が必要（イベント駆動への移行）
- スリッページ・約定モデルを精緻化しないと過大な期待値になる

---

## 候補2: COT (Commitments of Traders)

| 軸 | 評価 | 詳細 |
|---|:---:|---|
| コスト | ★★★★★ | CFTC 公開データ、無料、CSV 形式、毎週金曜更新 |
| 期待効果 | ★★★ | 投機筋のポジション極端値は中期トレンド転換の有効なシグナル。FX研究文献でも確立されたファクター |
| 実現可能性 | ★★★★★ | 週次更新の構造化データ、取得・保管・統合が容易 |
| **総合** | **★★★★** | **コストパフォーマンスが圧倒的に高い。最初に試すべき候補** |

### 想定される戦略
- 投機筋ロング偏重時の逆張り（contrarian）
- 商業筋（実需）と投機筋のスプレッド拡大期の方向取り
- COTシグナルを既存戦略のエントリーゲートとして使う（フィルタ）

### 注意点
- 週次データなので**日中戦略には粒度が荒い** → 週足/日足戦略向き
- CME futures データなので OTC FX とは厳密には異なる（相関は高い）
- リアルタイム取得不可（金曜引け後に火曜分公表）

---

## 候補3: マクロ/経済指標 + 金利差

| 軸 | 評価 | 詳細 |
|---|:---:|---|
| コスト | ★★★★ | FRED API (St. Louis Fed) 完全無料、ForexFactory カレンダーも無料 |
| 期待効果 | ★★★★ | 金利差はFXリターンの最大要因（キャリートレード）。指標発表時のボラ管理は実務必須 |
| 実現可能性 | ★★★★★ | 構造化API、文書化良好、レート制限緩い |
| **総合** | **★★★★** | **COTと並んでコスパ最高。実装も容易** |

### 想定される戦略
- 金利差ペア（USDJPY、AUDJPY 等）の中長期キャリー
- 指標発表時のボラ拡大期に既存戦略のリスクサイズを縮小
- 政策金利変化のサプライズを利用した日中ブレイクアウト

### 注意点
- ファンダメンタル統合は「シンプルなフィルタ」から始めるべき（過度なルール化で過学習）
- 政策金利は離散変数、戦略への組込み方が非自明
- 経済指標カレンダーは「重要度」がベンダー定義で曖昧

---

## 候補4: センチメントデータ (NLP / news / social)

| 軸 | 評価 | 詳細 |
|---|:---:|---|
| コスト | ★★ | 高品質商用（Refinitiv MarketPsych等）は $$$、無料代替は信号品質に問題 |
| 期待効果 | ★★ | 学術文献でも結果が分かれる。リテール NLP の有効性は限定的 |
| 実現可能性 | ★★ | データ取得・NLP処理・リアルタイム性すべてに技術的ハードル |
| **総合** | **★★** | コスト/効果比が悪く、優先度低 |

### 注意点
- Twitter API の事実上の閉鎖で、無料社会データ取得が大幅に難化
- NLP モデル（FinBERT 等）は事前学習済みモデルが使えるが、FX 特化は少ない
- 中央銀行声明（FOMC, BoJ）の構造化分析は別途価値ある（候補3に含めるべき）

---

## 候補5: 板情報 / オーダーブック (DOM, level-2)

| 軸 | 評価 | 詳細 |
|---|:---:|---|
| コスト | ★★ | 過去データは入手困難、商用は $$$。一部 ECN は API で生板取得可能 |
| 期待効果 | ★★★ | 注文フロー・流動性の偏りを利用したスキャルピング。HFT領域 |
| 実現可能性 | ★ | リテール環境ではほぼ実現不可（執行速度・データ品質） |
| **総合** | **★** | 個人開発スコープ外。研究目的としても投資対効果が悪い |

---

## 候補6: FXオプション / 暗黙ボラ (CVIX等)

| 軸 | 評価 | 詳細 |
|---|:---:|---|
| コスト | ★★★ | CME FX オプションのデータは部分無料、リアルタイムは要購読 |
| 期待効果 | ★★★ | リスクオン/オフの先行指標、レンジブレイク予兆 |
| 実現可能性 | ★★★ | データ取得は可、計算/解釈はそれなりの専門知識必要 |
| **総合** | **★★★** | キャリーやマクロと組み合わせる二次データとしては有用 |

## 推奨優先順位

### Phase 1（最初に試すべき）
1. **COT データ統合** — 無料・週次・確立されたファクター。週足/日足戦略のフィルタとしてMVP実装
2. **マクロ/金利差統合** — FRED API + 経済カレンダー。USDJPY のキャリー戦略 + 指標時間帯フィルタ

### Phase 2（Phase 1で改善が見られた場合）
3. **FXオプション ボラ統合** — Phase 1 戦略のリスクオン/オフフィルタとして
4. **ティックデータバックテスト** — マイクロ構造戦略の研究

### Phase 3（業界レベルの探索）
5. **センチメント** — 中央銀行声明の構造化分析に限定
6. ~~オーダーブック~~ — スコープ外

---

## Phase 1 を実行する場合の前提条件

将来 1h ORB を再開する代わりに、**新戦略カテゴリを Phase 1 データで構築**することが正攻法。具体的には:

- **戦略候補1**: 週足USDJPY × COT逆張り（投機筋ロング極値で売り）
- **戦略候補2**: 日足USDJPY × 金利差順張り（カバードキャリー型）
- **戦略候補3**: 既存ORB × 経済指標発表時間帯のリスク縮小フィルタ

Phase 1 実装コスト見積:
- COT データパイプライン: 1〜2日
- FRED API 統合 + 金利差テーブル: 1〜2日
- 1戦略実装 + WF検証: 3〜5日
- 計: **1〜2週間**で Phase 1 MVP が動かせる

## 重要な但し書き

本ロードマップは**実装計画ではない**。実行する場合:

1. ユーザーが明示的に Phase 1 開始を承認
2. ブレインストーミング → 設計 → 実装プラン → 実装の通常フローを踏む
3. データ取得テストで「期待した品質か」を確認してから戦略開発に移行
4. 「既存FXフレームワークが使えるか」も再評価（時間軸変更の規模次第ではauto-stock-traderから再構築のほうが速い）

実行しない場合、本書は**FXに戻る判断材料**として保管される。
